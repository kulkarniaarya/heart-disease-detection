AI Based Heart Disease Detection Using 2D Echo Images

 Overview
This project is an AI-powered Heart Disease Detection System that predicts whether a patient has a heart disease using 2D Echocardiography images.

The model uses Deep Learning techniques to classify images into Normal and Abnormal categories.

---

Features

- Upload 2D Echo Image
- AI Prediction
- Confidence Score
- Easy-to-use Interface
- Fast and Accurate Detection

---

Tech Stack

- Python
- TensorFlow / Keras
- OpenCV
- NumPy
- Streamlit

---

Project Structure

heart-disease-detection/

├── app.py

├── train.py

├── requirements.txt

└── README.md

---

 Model Performance

- Training Accuracy: 78%
- Testing Accuracy: 81.6%

---

## ▶️ How to Run

1. Clone Repository

git clone https://github.com/YOUR_USERNAME/heart-disease-detection.git

2. Install Packages

pip install -r requirements.txt

3. Run Project

streamlit run app.py
